Target App Development :
- Web (Dengan Landing page frontend & Admin Panel, Chat Portal dan linnya)
- Android React Native (Setelah Api Pindasi & Web App Selesai). Hanya untuk chat system only

Framework Stack :
- Adonisjs, Vite, Vue & Inertia
- UI: Shadcn + tailwindcss dengan Dark / Light mode
- DB: Postgresql, Redis, RabbitMQ
- Storage: Minio
- Deployment: Docker local (development) & Docker Ubuntu Server + Nginx (Production)
- Additional: Centrifugo (Websocket jika diperlukan websocket versi advance untuk keperluan Web App & Mobile App)
- Monitoring: Grafana, Promtheus, Loki & Promtail
- Lainnya jika ada yang saya lupa sebutkan yang perlu ditambahkan sesuai rekomendasi

A. Fitur :
- Multi Tenant dengan role permision: Divisi / Group -> Supervisor & CS Agent
- Divisi: Pembagian group / kelompok oleh Owner dengan pengelompokkan Supervisor, Agent CS dan Channel - channel assign
- Channel management dengan limit type User subscription. Add, Edit (Owner Only)
- Management Add, Edit & Delete Supervisor (Owner permission)
- Management Add, Edit & Delete Agent CS (Owner permission)
- Management Contact pelanggan masuk yang kesimpan ke database dengan label channel (CRUD hanya Edit, Block, Delete & Export CSV)
- AI Integration Pintar untuk membantu Auto chat response pelanggan AI Agent. Di bundle per token / subscription plan
- Fitur Webchat - AI Chatbots And Agents (Floating Chat Bubble: Untuk diintegrationkan ke any website dalam bentuk script integratiion
- Linkchat: Link seperti "wa.me", tapi ini untuk share link group
- Management Label: Untuk menandai Convertation Chat oleh agent seperti (new customer, pending payment, delivered dan lainnya). Dengan custom label bisa dibuat oleh Owner, supervisor dan agent tetapi harus unique dalam 1 tenant
- Blocked contact
- Auto reject call untuk channel whatsapp WAHA, Jika di aktifkan ketika ada pelanggan telpon masuk auto reject dan auto response balas otomatis
- Setup response otomatis untuk tiap - tiap channel (Owner & Supervisor permisiion only)
- Setup agent working hourse (Owner & Supervisor)
- Management balas cepat seperti pada ehatsapp business. Dengan type (Text Only, Text + Media Image & Text With Media Video). Struktur balas cepat (label shortcut & isi pesan / content)
- Webhook untuk integration channel yang membutuhkan setup ini
- Archived chat
- Dan lainnya jika ada yang saya lupa sebutkan yang perlu ditambahkan sesuai rekomendasi
